# Draft dependencies and provenance

The design has no React dependency, package manager, CDN runtime dependency, or
new hosting service. The approved production build selects LabDraft and serves
the following assets locally. The Three.js scene is loaded only on the homepage;
the Archify viewer is linked from the cache report and its featured card.
Scoped `.gitattributes` entries preserve the pinned files and frozen diagram
specification byte-for-byte on Windows checkouts.

## Archify

- Project: https://github.com/tt-a1i/archify
- Source commit: `18911058008f17dc065af23a2cdc9bfeff6d3f7a`.
- Used the repository's `archify/SKILL.md` schema/validate/deliver workflow.
- The tool checkout is local-only at `.local-tools/archify`; it is not globally
  installed or included in the site. The version has not been auto-updated.
- Generation source: `design/diagrams/dataset-cache.architecture.json`.
- Output: `themes/LabDraft/static/lab/diagrams/dataset-cache.html`.
- The upstream MIT notice is included as `vendor/ARCHIFY-LICENSE.txt`.
- No third-party brand marks are requested by this specification.
- The generated viewer embeds JetBrains Mono subsets under SIL OFL 1.1; the
  complete font license is carried in the generated HTML's font CSS. Korean
  glyphs use system fallback fonts, so their rendering varies by platform.
- Korean diagram annotations are for this review draft. The surrounding site
  and existing reports remain English; fixed Archify controls and its HTML
  language fall back to English for this unsupported viewer locale.

The concept geometry is custom Three.js code. It is not a model of NVIDIA or
Apple hardware and does not depict a measured memory allocation.
